Case Study 01

Online Voting System

A Java Swing desktop application for managing an election process from registration to results.

What I built

The system organizes different roles and election actions. Voters can register, candidates can be managed, and authorized users can review requests and view election results.

Key features

  • Admin, voter and supervisor roles
  • Voter and candidate registration
  • Request approval workflow
  • Live election results
  • Winner declaration and election reset

What I learned

This project helped me practice classes, inheritance, polymorphism, encapsulation, static data structures, event handling and Java Swing GUI design.
