# Syed Ali Sher Kazmi — Portfolio

## Upload to GitHub Pages
Upload these files to the root of your GitHub Pages repository:

- index.html
- about.html
- projects.html
- experience.html
- contact.html
- style.css
- script.js
- assets/

The project image filenames expected in `assets/` are:
- voting-admin.png
- number-guessing.png
- library-manager.png

If your existing image filenames are different, rename/copy them to those names or update the `src` values in `projects.html`.

## Before publishing
Replace the placeholder email in `contact.html` and add your real CV URL and booking URL when available.

## Animation
Navigation between HTML pages uses a short fade transition. Cards and content also use subtle entrance/hover animations. A reduced-motion setting is included for accessibility.
