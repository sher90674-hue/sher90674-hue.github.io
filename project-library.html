Case Study 03

Library Book Manager

A desktop library-management application for tracking books, members, issues/returns and loans.

What I built

The application organizes library records through separate sections for books, members, issuing/returning books, and loan/fine tracking.

Key features

  • Book inventory management
  • Member registration
  • Issue and return workflow
  • Loan and fine tracking
  • Search and sorting functions

What I learned

This project helped me practice GUI design, event handling, data management and building a multi-section desktop application.
